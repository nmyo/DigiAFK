# Poke'Catch 单机离线版

原站 [Poke'Catch](https://pokecatch-online.pages.dev/) 的**完全离线单机版**：前端 100% 使用原站代码
（含中文语言包与全部素材），将 Supabase 后端替换为本地游客模式——**无账号、无云端**。联网时会请求本域资源和版本文件，
进度由原站自身的游客存档机制保存在浏览器 localStorage（`pokecatch-anon`）。

## 架构

```
index.html（原站 shell 页，仅 3 行适配）
 └─ ./boot.js        ← 原 boot.js，仅把 CDN 域替换为部署根（new URL('.',location)）
     ├─ bundle/app.9258c082d1.css      原站样式（内嵌像素字体）
     ├─ bundle/vendor-supabase.*.js    独立本地游客适配器
     │    └─ createClient 被替换为「永远未登录 + 全部调用静默空转」
     ├─ bundle/app.c74e480997.js       原站游戏逻辑 + 本地规则补丁
     ├─ bundle/lang-*.js               简体与繁体中文语言包
     └─ assets/                        原站素材 2200+（精灵/道具/UI/场景）
```

离线适配层改动：

1. `index.html`：SW 注册相对路径、脚本指向本地 `./boot.js`、保留 BOOT_FAIL 兜底
2. `boot.js`：文本替换 `https://pokecatch-online.pages.dev/` → `""+(new URL(".",location))+"`（12 处）
3. `vendor-supabase.js`：由独立游客适配器替代原 vendor（不联网、不登录、社交功能空数据）

本地规则补丁将现有四种连接绳通信进化改为 46 级，并为现有原作通信持物进化增加 46 级路径；其他通信持物进化的原道具路径仍保留；连接绳在原游戏中是交换标记而非普通可用道具，其原交换路径被替换，珍珠贝的两个 46 级分支可在进化时选择。游戏未定义的通信进化不在此次范围内。普通金币商店价格为原价的 20%（取整且最低 1），其出售价格同步降低；其他货币商店不变。默认速度设为 4。主线普通道馆战的敌方 HP 降为原来的 25%、伤害降为原来的 50%；联盟、活动、区域、塔及精英战不受此道馆补丁影响。常规传奇区域遭遇的敌方 HP 降为原来的 10%，直接攻击伤害倍率降为原来的 25%；队伍人数仍按游戏原有机制影响敌方 HP 和伤害，其中急冻鸟（144）的基础 HP 倍率另从 3.74 降至 3.37、火焰鸟（146）从 34.18 降至 30.76；该区域的传奇及幻之宝可梦无加成实际捕获概率为 90%。挑战普通传奇区域首领开始时，当前出战队伍的 HP 恢复至最大（包括濒死成员，状态和 PP 不变）；精英、团体战和世界 Boss 不受传奇区域补丁影响；区域外的传奇捕获规则不变。这些倍率不保证任意 90 级满编队伍都能获胜：属性、招式、状态和狂暴等仍会影响战斗。重建时会重新校验并应用这些补丁。

野生遭遇及区域出没列表不再因天气排除区域配置的种类；昼夜、地区进度和传奇宝可梦等其他条件仍按原规则执行。天气不再影响野生遭遇选择概率或权重；天气及其战斗效果保留。普通区域的出没面板列出该区域的物种，并以 NEW 标记未收录的物种，不再显示天气、条件分组或遭遇概率。

## 本地试玩

```bash
cd site && python3 -m http.server 8080   # 打开 http://localhost:8080
```

首次联网访问只尝试预缓存核心资源，且单项下载失败不会阻止安装；图片通常按访问需要缓存。因此首次访问后不保证所有图片均已离线可用，浏览器也可能清除缓存。

速度按钮的最高档保存值为 4，但游戏的战斗节奏倍率映射为 2.5，因此标记为 ×2.5。

## 部署

- **GitHub Pages**（推荐，国内可直连）：`bash scripts/deploy-pages.sh` → <https://nmyo.github.io/DigiAFK/>
- 校验并应用离线补丁：`node scripts/build-offline.cjs`。以仓库中的 `site/` 为本地基线，无需外部镜像；这不是从原站源码重新生成游戏包。
- GitHub Pages 部署脚本会注入构建号，供首次版本请求失败后恢复检测；其他部署方式默认使用 `dev`，不会自动生成唯一版本号，版本轮询可能无法检测更新。其他平台需自行同时生成匹配的页面 `pc-build` meta 和 `version.json` 版本号。
- ⚠️ `*.vercel.app` 默认域名在国内被 DNS 污染 + SNI 阻断，需绑定自有域名才能访问

> 前端代码与素材来自 Poke'Catch 原站。

语言仅提供简体与繁体中文；旧的非中文偏好回退简体。压缩的上游游戏 bundle 仍含法语原文及部分多语言运行时代码，因与游戏逻辑耦合而保留。
